# IntelliCode

A Context-Aware Development Environment with Persistent Project Intelligence.

## 🚀 Features

- **VS Code / Antigravity File System & Editor**: Live file creation, nested folder trees, local directory import (`window.showDirectoryPicker`), and live editing with dirty file indicators.
- **Model Gateway & Persistent Project Context**: Seamless, zero-context-loss model switching between Claude 3.5 Sonnet, GPT-4o, Gemini 2.0 Pro, and DeepSeek R1.
- **Change Impact Analysis (CIA) Studio**: Real-time blast radius calculations, identifying direct dependents and transitive ripples, with proactive test recommendations.
- **Centralized MCP & Integration Hub**: Centralized manager for GitHub, PostgreSQL, Puppeteer Browser Automation, and Slack MCP servers with interactive JSON-RPC sandbox testing.
- **Validation Engine**: Automated test runner executing targeted tests against affected components.
- **Empirical Evaluation Suite**: Interactive benchmarks based on the research paper specification.

## 📦 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
